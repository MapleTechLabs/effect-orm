MySQL and MariaDB upserts: `insertInto(table).values(rows).onDuplicateKeyUpdate({ set })` writes `INSERT ... ON DUPLICATE KEY UPDATE`. `set` takes the forms `onConflictDoUpdate`'s does: a record of values, params or expressions, a callback `($, excluded) => ({ ... })` of the existing and proposed rows, `excluded(columns)` or `excludedAll(except?)`. MySQL reads the proposed row through a row alias, `VALUES (...) AS excluded` (MySQL 8.0.19+); MariaDB reads `VALUES(col)`. (For MySQL before 8.0.19, spread `mysqlDialect` with `clauses.onDuplicateKey: "valuesFunction"`.) It fires on any unique key and takes no target or `where`, so `excludedAll` leaves out the table's declared primary key and its `tenantColumn`, and a bare `excludedAll()` on a table with no declared key is a `QueryBuilderDefect` asking for `except`. On a table with a `tenantColumn` the insert is `"cross-tenant"`. A proposed-row column the SET reads but no row writes joins the insert with `DEFAULT` cells, as Postgres's `excluded` holds the default. `values` rows only; with `select`, on a table named `excluded` on MySQL, or on another dialect, compiling is a `QueryBuilderDefect`. `onConflictDoUpdate` / `onConflictDoNothing` on MySQL now name `onDuplicateKeyUpdate` / `onDuplicateKeyDoNothing` in their errors, and the reverse on Postgres and SQLite. New: `Dialect.clauses.onDuplicateKey`, and the `OnDuplicateKeyUpdate` type.

`onDuplicateKeyDoNothing()` skips a row that conflicts on any unique key, on MySQL and MariaDB. It writes `ON DUPLICATE KEY UPDATE col = table.col` on the first written column, not `INSERT IGNORE`: `IGNORE` also turns truncation, NOT NULL and foreign key errors into warnings and stores or drops the row, while these still fail. A skipped row counts as 1 affected row with mysql2's default `CLIENT_FOUND_ROWS`, 0 without it. It keeps the inserted rows' tenant scope, since the statement writes no existing row; it is still an UPDATE of the matched row, so a `BEFORE UPDATE` trigger runs, and then `affectedRows` is 2 and `insertId` the matched row's id.
